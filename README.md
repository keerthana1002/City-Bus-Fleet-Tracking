## Fixed Case Parameters
- **Fleet Size:** 600 buses
- **Core Features:** Live location, arrival prediction, driver duty roster
- **Operational Constraint:** GPS signals drop in tunnels
- **Process Model (Module 1):** Spiral
- **Agile Method (Module 2):** Kanban
- **AI Tools Used:** ChatGPT
- **Prototype Module:** Arrival time estimator (`src/arrival_estimator.py`)

---

## How to Run in VS Code
1. Extract this ZIP file to a folder on your computer.
2. Open VS Code -> **File > Open Folder...** -> select the extracted folder.
3. Open `main.py` and click **Run Python File (▶)** or press **F5**.
4. Run all 8 unit tests via the VS Code Testing tab or terminal: `python -m unittest discover -s tests -v`.
