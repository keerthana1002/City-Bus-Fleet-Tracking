# Lab L5.4 [Advanced]: Finding & Fixing a Deliberate Weakness in AI-Generated Code

## 1. Deliberate Weakness Found in AI-Generated Telemetry Parser
When asked to generate a quick telemetry packet parser for the 600-bus fleet, AI produced:
```python
# VULNERABLE AI-GENERATED SNIPPET
def parse_telemetry_unsafe(raw_payload: str) -> dict:
    # Deliberate weakness: uses eval() and lacks input validation on numeric fields
    data = eval(raw_payload)
    eta = (data["distance"] / data["speed"]) * 60
    return {"bus_id": data["bus_id"], "eta": eta}
```
- **Weakness 1 (Arbitrary Code Execution — CWE-95):** `eval(raw_payload)` executes arbitrary Python code if a malicious or corrupted GPS gateway string is received.
- **Weakness 2 (Missing Input Validation — CWE-20):** Fails with `ZeroDivisionError` when `speed == 0` (e.g., inside a tunnel) and allows negative distances.

## 2. Secure Fix Applied
```python
import json

def parse_telemetry_safe(raw_payload: str) -> dict:
    data = json.loads(raw_payload)  # Safe JSON parsing only (no code execution)
    bus_id = str(data.get("bus_id", "")).strip()
    distance = float(data.get("distance", -1))
    speed = float(data.get("speed", -1))

    if not bus_id:
        raise ValueError("Invalid or empty bus_id")
    if distance < 0 or speed < 0:
        raise ValueError("Distance and speed must be non-negative")

    safe_speed = max(speed, 5.0)  # Minimum speed floor prevents ZeroDivisionError
    eta = round((distance / safe_speed) * 60.0, 2)
    return {"bus_id": bus_id, "eta": eta}
```

## 3. Verification Test
- **Payload 1 (Code Injection Attempt):** `'__import__("os").system("echo hacked")'` -> `parse_telemetry_safe()` immediately raises `json.JSONDecodeError` (blocked).
- **Payload 2 (Zero Speed in Tunnel):** `'{"bus_id": "BUS-028", "distance": 2.5, "speed": 0.0}'` -> safely clamps speed to `5.0 km/h` and returns `{'bus_id': 'BUS-028', 'eta': 30.0}`.
