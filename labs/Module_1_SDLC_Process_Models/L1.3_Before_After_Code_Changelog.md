# Lab L1.3 [Applied]: Hand-Written vs. AI-Improved Arrival Time Estimator

## 1. Before Code (Hand-Written Baseline)
```python
def estimate_arrival_handwritten(distance_km, speed_kmh, gps_active):
    # Basic hand-written calculation without tunnel dead-reckoning or smoothing
    if not gps_active:
        return -1  # Fails when bus enters tunnel
    if speed_kmh <= 0:
        speed_kmh = 20.0
    eta_minutes = (distance_km / speed_kmh) * 60
    return round(eta_minutes, 2)
```

## 2. After Code (AI-Improved with Tunnel Dead-Reckoning & EMA Smoothing)
See `src/arrival_estimator.py` (`ArrivalTimeEstimator.estimate_eta`), which adds per-bus Exponential Moving Average (`_ema_speeds`) smoothing, `TUNNEL_DEAD_RECKONING` distance projection during GPS drops, traffic factor adjustment, and strict input validation.
