# Lab L3.5 [Advanced]: Dockerfile, Line-by-Line Explanation & Execution Proof

## 1. Line-by-Line Explanation of `Dockerfile`
1. **`FROM python:3.11-slim`**: Pulls a lightweight Debian-based Python 3.11 image (~130 MB) to keep container builds fast and minimal.
2. **`ENV PYTHONDONTWRITEBYTECODE=1 PYTHONUNBUFFERED=1`**: Stops Python from generating `.pyc` bytecode files and streams `print()` logs immediately to Docker stdout.
3. **`WORKDIR /app`**: Creates and sets `/app` as the active directory inside the container.
4. **`COPY requirements.txt .`**: Copies only `requirements.txt` first so Docker caches the dependency layer.
5. **`RUN pip install --no-cache-dir -r requirements.txt`**: Installs `pytest` cleanly without keeping wheel caches in the image layer.
6. **`COPY src/ ./src/` (plus `data/`, `tests/`, `main.py`)**: Copies the Arrival Time Estimator prototype, 600-bus datasets, tests, and master runner into `/app`.
7. **`CMD ["python", "main.py"]`**: Runs the 600-bus Arrival Time Estimator prototype automatically when the container starts.
